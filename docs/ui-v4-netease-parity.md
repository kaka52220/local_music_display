# UI v4：对齐网易云平板端（底座 / 唱臂 / 切歌流畅度 / 分栏布局 / 控制按钮）

参考：网易云平板端录屏（左播放器 + 右歌词）逐帧对比，以及我们 v3 的录屏。

## 1 & 6. 切歌：底座固定，只有黑胶在滑；动画重构
- 结构拆分：`.disc-base`（浅色半透明底座圆环）固定在 `#disc-stage` 里，**永远不动**；
  三张黑胶 `.disc-slot`（上一首 / 当前 / 下一首）各自独立设置 `transform: translate3d()` + `opacity`。
- 运动模型（`public/js/ui/discCarousel.mjs`）：一个连续量 `p`（单位 = 唱片间距），槽位 r 显示在 `(r+p)×间距`。
  任何切歌（按钮、歌单、自动下一首、甩动松手）都是：先"换角色"让新歌成为中心、`p += dir`，再让 `p → 0`。
  中心唱片始终 = 引擎当前曲目，快速连点只是叠加 p，不会错乱，也不需要排队。
- `p → 0` 用临界阻尼弹簧的**解析解**逐帧推进（rAF，只改 transform/opacity，无布局抖动）。
  切歌时同时叠加 `-ω·dir` 的初速度，轨迹正好是指数衰减 = 起步快、平滑减速的 ease-out，且不过冲；
  被打断时保留当前速度，轨迹连续。ω = 13/s，约 380ms 完成 99%。
- 透明度随距离变化：离中心 0.3 个间距内不透明，1 个间距处完全消失 → 旧唱片快速淡出、新唱片淡入，重叠很少。
  唱片区两侧再加一道柔和渐隐遮罩，滑出栏外不会被硬切。
- 拖动：1:1 跟手（可从动画中途无缝接管），超出一个间距加阻尼；松手按位移/速度决定切歌或回弹。
- 唱片旋转：所有黑胶共用"是否在转"的状态，切歌过程中旋转不停；回收的唱片重置为 0°。
- 调试：`http://localhost:8080/?slowmo=10` 把切歌动画放慢 10 倍，方便逐帧检查。

## 2. 唱臂：播放中切歌不抬起
- 引擎（`player/engine.mjs`）把"播放意图"和"实际出声"分开：`playstate` 表示用户想播放（切歌加载期间不变，按钮不闪），
  新增 `audible` 事件（`playing` → true；`waiting/pause/emptied/stalled/ended` → false）。
- 唱臂规则：`落下 = 想播放 && (正在出声 || 切歌宽限期)`。播放中切歌给 1.5s 宽限，本地文件加载远小于此，所以唱臂不动；
  暂停时抬起；从暂停状态开始播放 / 暂停时切歌，要等音频真正出声（`playing`）后才落下——与录屏"只有前几秒歌没播放时才抬起"一致。
- 起落：落下 560ms、抬起 420ms，均为 ease-out 曲线；唱针落稳后唱片才开始转。

## 3. 新增"分栏布局"+ 右上角布局选择弹窗
- 分栏布局（`data-layout="split"`）：左 45% —— 唱片（固定底座 + 唱臂）、歌名（大号白色）/歌手（灰色）+ 喜欢/歌词按钮、
  进度条（两端时间）、播放控制（模式 / 上一首 / 播放 / 下一首 / 歌单）；右 55% —— 顶部署名信息（歌手 / 专辑 / 来源）+ 歌词，
  当前行大且亮，其余半透明。分栏布局下隐藏底部控制栏。
- 经典布局保留为另一个选项。
- 同一套 DOM：切换时把控制按钮组和进度条节点在底栏 / 左侧信息区之间移动，事件绑定不变；
  用 View Transitions 交叉淡入（不支持时退化为淡入淡出）。选择存 `localStorage`（`local-player/layout/v1`）。
- 右上角新增布局按钮，弹出毛玻璃弹窗：带指向小三角、弹性展开、选项依次浮入；每个选项用纯 CSS 画迷你预览图，
  选中态为红色描边 + 对勾徽标；点击外部 / Esc / 选择后关闭，支持左右方向键。
- 喜欢（红心）按曲目存 `localStorage`（`local-player/likes/v1`），带弹跳动画。
- 两种布局下：左上角歌单底部弹窗、歌词拖动定位（时间 + "点击从这里播放 ▶"）、唱片拖动切歌都可用。

## 4. 唱臂重画（SVG）
- 转轴：深色底盘 + 金属旋钮（径向渐变、同心圆环、中心轴、高光点）；
- 配重：转轴后方伸出的金属圆柱（横向渐变 + 刻线）；
- 臂管：三层描边（暗边 / 主体 / 高光线）做出圆柱立体感，弯曲走向对齐网易云；
- 关节套环、唱头连接颈、带散热纹的唱头壳、指拨、黑色唱头与针尖；
- 双层投影（贴合投影 + 随唱片尺寸缩放的落影）投在唱片上。

## 5. 播放控制按钮重画
- 对齐网易云平板端：播放 / 暂停 / 上一首 / 下一首为**实心圆角块面、无外圈**；
  三角形用二次曲线倒角生成（不再用"填充 + 同色粗描边"，避免半透明颜色下出现一圈亮边的"塑料感"）。
- 模式 / 歌单等次要图标改为 1.9 线宽粗线条；主控加淡投影，按下有回弹缩放。
- 尺寸：分栏布局播放键 60–76px，上一首/下一首 40–50px，按屏幕高度自适应。
