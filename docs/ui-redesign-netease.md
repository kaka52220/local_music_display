# 第一阶段：对齐网易云播放页视觉（分析与改动）

参考：`screenshots/ref/netease.png`（主参考）、`screenshots/ref/qqmusic.png`（辅助）
对比：`screenshots/before*.png` → `screenshots/after*.png`

## 为什么"形似神不似"
1. **背景**：旧版把封面直接高斯模糊+提饱和铺满，颜色脏、发蓝发青、明暗斑驳；网易云是"封面主色 → 大幅降饱和、压暗"的近纯色竖向渐变，安静、高级。
2. **布局重心**：旧版把进度条+控制按钮塞在左栏唱片下方，左重右轻；网易云左栏只有唱片，控制统一放在全宽底栏，右栏是 信息→Tab→歌词 的清晰纵向节奏。
3. **黑胶**：旧版唱片偏小、封面只占 58%，唱纹是粗条纹；唱臂粗、头部像方块、整体卡通。网易云：外圈半透明光环 + 纯黑唱片 + 大封面（≈69%）+ 极细唱纹；唱臂是细白线、转轴有深色底座、唱头小而精致，暂停时向右上抬离。
4. **字体层级**：旧版标题 700 粗体、辅助信息灰度单一；网易云标题 500 字重、辅助信息 12–13px 60% 白，层级靠"灰阶"而不是"粗细"。
5. **歌词**：旧版字号小、行间夹大段空行、当前行切字号导致跳动、居中位置偏下；网易云非当前行 40% 白、当前行纯白加粗略放大、停在视区上部约 40%，上下渐隐。
6. **控制栏**：旧版 5 个大图标横向撑满、无主次；网易云底栏细密：左侧歌名/歌手，中间 模式/上一首/播放(圆形浅底)/下一首/列表，右侧 音质/词/音量，进度是贴顶的 2px 细线。
7. **细节**：旧版几乎没有统一的线宽、圆角、透明度体系；网易云图标统一细线宽、颜色只用 4 档白色透明度，红色仅点缀。

## 改动
- 背景：canvas 提取封面"饱和度加权主色" → HSL 降饱和压暗生成上下两色渐变，切歌 1.2s 过渡；叠加 16% 透明度的超大模糊封面只做色彩起伏。
- 布局：Grid 三行（顶栏/舞台/底栏）；舞台 48:52 两栏，唱片中心 ≈29vw，右栏起点 ≈48vw，对齐截图比例。
- 黑胶：光环 + 黑胶 + 唱纹（SVG 细同心圆，避免摩尔纹）+ 静态斜向高光；旋转用 animation-play-state 暂停/继续，不跳帧；唱臂 SVG 按截图像素比例重画，播放落下、暂停抬起（0.55s 缓动）。
- 右栏：标题 + 格式标签、专辑/歌手/来源、歌词/百科/相似推荐 胶囊 Tab（后两项为占位）。
- 歌词：当前行用 transform: scale 放大（不触发重排、不跳动）+ 颜色过渡；空行压缩；当前行定位 40%；手动滚动 3 秒无操作自动回到当前行；悬停行可从该句播放。
- 底栏：全宽，进度细线贴顶（悬停加粗变红并出现拖拽点）、左侧歌名/歌手/时间、中间五键、右侧 音质标签/词（显隐歌词）/音量（悬停弹出滑块，记忆音量）。
- 播放列表：改为右侧毛玻璃面板，底栏列表键与左上角按钮均可打开。
- 图标：全部重绘为 24 网格内联 SVG，线性图标统一 1.6 线宽。
- 其他：空格键播放/暂停；窄屏自动上下堆叠。
