# v10：手机竖屏 / 横屏适配

## 参考与取舍
用 ffmpeg 逐帧查看用户提供的 Android 网易云录屏（约 22 秒），参考其中的音乐库 → 底部迷你播放器 → 上滑完整播放页、封面/歌词切换。
没有复制/提取网易云资源，所有按钮复用本项目自绘 SVG。

- 音乐库：深灰棕渐变，顶部封面拼图（取本地歌曲封面）模糊淡出；固定「我的音乐」和搜索；「本地音乐库」+ 歌曲数量；吸顶红色「播放全部」；方形圆角封面 + 歌名 / 歌手·专辑。
- 底部迷你播放器：半透明毛玻璃、小圆封面（24 秒一圈，暂停时停在原角度）、歌名歌手、播放/暂停、队列。点击歌曲或迷你条，完整播放页 300ms 上滑；收起按钮 300ms 下滑。
- 完整播放页：大圆角方封面，宽约屏宽 80%（360/390/412px 下分别 288/312/330px；受高度限制以免挤压控制区），不是把平板唱片硬缩小。
  歌名 / 歌手、共享「喜欢」按钮、44px 命中区进度条（小白圆点常显）、五个均布控件：模式 / 上首 / 圆框播放暂停 / 下首 / 队列。底部只留定时、歌词/封面切换。
- 封面和歌词 200ms 淡入淡出，封面轻微缩小；歌词居中，当前句略大加粗，保留原逐字高亮 / 输出延迟补偿 / 0.1 秒步进全局微调 / 拖动定位。
- 下滑收起：只在封面和标题栏这两个不滚动的区域启用，跟手 1:1。超过页面高度 20%（最多150px）或明确下甩才收起，否则弹回。
  歌词区的拖动仍用于找歌词，不抢进度条/按钮事件；系统取消触摸时弹回。
- 复用原歌单底部弹窗和睡眠定时弹窗，手机尺寸单独适配，不做第二套功能。

删减：没有头像、播放量、分享、评论、收藏统计、VIP/音质标签、歌曲百科、投屏、EQ、下载、多选、无实际用途的更多菜单。
音乐库是根页面，没有假返回键。手机隐藏全屏、平板布局切换器和 v9 迷你歌词条；高斯/流体背景沿用已有选择，不另放设置入口。

## 启用条件与平板隔离
`(max-width:600px)`，或 `(max-width:950px) and (max-height:500px) and (pointer:coarse)`。
前者适合窄竖屏，后者确保手机旋转横屏不会掉回平板布局，不使用 UA 猜设备。1024px 平板不受影响。

独立 `phone.mjs` / `phone.css`。CSS 全部限定在 `.phone-ui` 下；共享歌词节点、背景节点、喜欢按钮只在手机模式移入手机壳，离开时原位恢复。
共享引擎/时钟/播放队列，屏幕旋转与窗口变宽不会重新载入音频。
使用 `100dvh` 与四侧 safe-area；按钮命中区 ≥44px、无横向溢出；遵守 reduced-motion（停止旋转并缩短过渡）。
**本轮服务端无改动。**

## 验证
- 360×780、390×844、412×915：音乐库、播放中的迷你条、封面、歌词、半途上滑、队列弹窗、定时弹窗截图。
- 844×390 横屏：相同流程；左侧封面/歌词，右侧信息和控制。
- 实际指针拖动进度到 70% → 音频位置约 70.36%；原生触摸拖到60% → 约60.17%；鼠标和 Chrome 原生触摸事件分别验证下滑跟手、短拖弹回、长拖关闭。
- 旋转封面随播放/暂停改变 animation-play-state；搜索/无结果/恢复列表、下一首、共享微调参数均验证。
- 模拟顶部44px/底部34px安全区，无遮挡且没有横向溢出；fluid 模式渲染正常；reduced-motion 下无旋转，页面过渡0.01s。
- 同一浏览器下 1280×800 的经典/分栏各拍 v9 基线和 v10 结果（暂停、固定动画），**逐像素比较完全相同**。
- v6、armtest、locate、kara、tapfx、v8 定时/全屏、v9 全套回归通过；手机测试与回归均无控制台错误。
- 截图：`screenshots/v10/`。未进行 Android 实机测试，使用 Chrome 移动端触摸/视口模拟；不会把模拟测试说成实机测试。

可重复执行手机自动化测试（默认内置三首示例，服务运行在8080）：
```sh
# 可选测试工具，不是播放器运行依赖
npm install --no-save --package-lock=false playwright-core
node tests/phone.mjs
node tests/phone-extra.mjs
node tests/phone-touch.mjs
```
Chrome 路径默认 `/usr/bin/google-chrome`，可用 `CHROME_PATH` 指定本机路径，`PLAYER_URL` 指定播放器地址。
