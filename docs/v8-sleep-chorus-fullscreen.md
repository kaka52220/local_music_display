# v8：定时关闭 · 高潮提示点 · 全屏 / 添加到主屏幕

## 1. 定时关闭（`public/js/ui/sleepTimer.mjs`）
参考录屏 `vids/sleep-ref.mp4`（抽帧观察），保留我们的深色网易云风格：
- 入口：时钟图标 +「定时」。分栏布局在「喜欢 / 歌词」中间，经典布局在底栏右侧「音质标签」与「词」之间；开启后变成红色胶囊 + 实时倒计时（mm:ss）。
- 弹窗：打开 ~340ms 缓出（末端轻微回弹）、遮罩同步变暗；关闭 200ms 缓入（更快）。标题开启后实时显示「mm:ss后自动停止播放」，右侧 × 关闭。
- 滑轨 0–90 分钟（关 / 30 / 60 / 90），胶囊拇指 1:1 跟手（实测偏差 0px）、内显整数分钟、数字上下滚动切换；按下放大 1.1；
  点轨道远处时拇指以指数缓动（τ=55ms）滑过去再跟手；经过刻度时拇指轻弹 + `navigator.vibrate(8)`；已选部分为主题色渐变。
- 「播完本首后关闭」：圆形勾选（主题色填充 + 对勾弹出），倒计时 = 本首剩余时长（拖动进度会跟着变），本首结束即停（不切下一首）。
- 到点：Web Audio 增益 4 秒平方曲线淡出 → 暂停，唱臂随播放状态抬起；淡出中用户手动暂停/切歌则结束定时。拖回「关」或点「关」取消。
- 状态写入 localStorage，刷新后继续倒计时。

## 2. 高潮提示点（v9 已删除）
v8 的高潮点是"歌词重复段 + 音频能量"**估算**出来的（歌曲文件里没有这个信息），不可靠。
按用户定下的规范——**做不到可靠的功能不用猜的方式实现**——v9 已整体删除：前端分析与进度线小白点/气泡、
服务端 `/api/chorus` 与 `cache/chorus.json`、歌词里的 `[chorus:]` 解析均已移除。
浏览器里遗留的 `local-player/chorus/v1` 本地缓存不再被读取，可忽略。

## 3. 全屏 / 添加到主屏幕
- 顶栏右侧（布局按钮左边）全屏按钮：`requestFullscreen({ navigationUI: 'hide' })`，含 webkit 前缀回退；图标展开/收起交叉旋转变形；监听 `fullscreenchange`（Esc / 返回键退出同步）；不支持（iPhone Safari）时隐藏；以全屏 App 启动时也隐藏。
- `public/manifest.webmanifest`：`display: fullscreen`（`display_override` 回退 standalone）、主题/背景色 `#1f1c1e`、自绘 PNG 图标 192/512 + maskable 512 + apple-touch-icon 180；apple-mobile-web-app 等 meta。
- 局域网 http 下浏览器多半只把它当快捷方式（真正"安装"需要 HTTPS），说明见 `平板访问说明.md` 第 5 节。
