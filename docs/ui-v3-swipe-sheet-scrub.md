# v3：唱片滑动切歌 / 质感优化 / 歌单弹窗 / 歌词定位

参考：`screenshots/ref/tablet-*.jpg`（网易云平板端）+ 用户录屏（唱片切歌手势）。

## 1. 唱片滑动切歌（`public/js/ui/discCarousel.mjs`）
- 3 个唱片槽（上一首 / 当前 / 下一首），中心距 = 直径 + 封面半径；Pointer Events 统一处理鼠标与触摸，1:1 跟手。
- 按下拖动：旋转立即暂停，唱臂 130ms 逆时针抬起 30° 并保持。
- 松手：位移 > 32% 中心距或快速甩动（> 0.45px/ms）→ 360ms ease-out 吸附到相邻唱片后才切歌；否则 300ms 回弹。
- 落定：唱臂 230ms 落下，落稳后（且在播放）才恢复旋转；新唱片从 0° 开始转。
- 背景/标题/歌词拖动中不变，切歌后交叉淡入；歌词先显示"歌词加载中..."再淡入。
- 上一首/下一首按钮、歌单点选、自动下一首走同一套滑动动画；随机模式下预先抽好"下一首"，预览与实际一致；列表首尾循环。
- 唱片区域聚焦时 ←/→ 键切歌。

## 2. 质感 / 立体感 / 呼吸感（三版对比，见 `screenshots/variants/`）
| 版本 | 思路 | 结论 |
|---|---|---|
| V1 氛围光 | 封面主色低饱和渐变 + 唱片背后随封面变色、缓慢漂移的"背光"光晕 + 右上弱光 | **采用**：有层次、有呼吸，唱片"浮"在光里，且仍保持网易云的克制 |
| V2 石墨 | 平板端同款中性 #2b2b2b 深灰，几乎无封面色 | 干净但千篇一律，切歌没有氛围变化，偏"平" |
| V3 沉浸模糊 | 大面积模糊封面 + 暗角 | 色彩最浓，但部分封面出现脏斑块，抢歌词视线 |

三版共用的改进：唱片三层软阴影（接触影/中距/环境影，随唱片移动）、黑胶环镜面高光（不盖封面）、封面内外双描边、唱臂金属渐变 + 双层投影、背景细颗粒防色带、更大的留白与行距、玻璃质感底栏与播放键。

## 3. 歌单底部弹窗（`public/js/ui/sheet.mjs`）
- 左上角按钮与底栏列表按钮打开同一弹窗；原右侧抽屉/列表视图已删除。
- 动效：遮罩 300ms 淡入；面板 420ms `cubic-bezier(.32,.72,0,1)` 自底部升起（iOS/网易云同类曲线，类弹簧无回弹）；关闭 260ms 更快。
- 把手/头部向下拖动 1:1 跟手（向上有阻尼），超过 25% 高度或快速下甩关闭，否则回弹；点遮罩或 Esc 关闭。
- 内容：当前歌曲（封面/歌名/歌手/共 N 首）、4 个快捷操作（播放全部/播放模式/定位当前/显隐歌词）、搜索（歌名/歌手/专辑）、全部歌曲（正在播放显示跳动均衡器条，暂停时静止）。点歌后弹窗先收起，再执行唱片滑动切歌。

## 4. 首页即播放页
- 打开 `http://localhost:8080` 直接进入播放主页面；无历史会话时默认选中第一首（暂停），唱片/封面/歌词/时长都可见。

## 5. 歌词定位（`public/js/ui/lyricsView.mjs`）
- 滚轮 / 鼠标拖动 / 触摸滑动歌词进入定位模式：焦点线（视区 40%）处的行左侧显示时间、右侧出现"点击从这里播放 ▶"胶囊（淡入 + 轻微右滑，200ms）。
- 滚动中显示细引导线；停下 160ms 后吸附对齐并过渡为圆角半透明高亮行（对应参考图 1 → 图 2）。
- 点击胶囊或该行：跳转并播放；3 秒无操作淡出并平滑回到当前播放行。
