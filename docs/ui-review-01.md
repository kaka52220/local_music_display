## P1 建议（含修改指导）
1. **背景氛围不足**：当前背景几乎是纯色，参考图有明显的封面色彩晕染。
   指导：降低 now-bg 的压暗程度、减弱遮罩，让模糊封面透出颜色。
2. **唱片质感偏平**：黑胶纹理不够明显，缺少真实反光。
   指导：叠加一道斜向高光，加强同心圆纹理与外圈光泽。
3. **唱臂落点偏外**：唱臂头部停在唱片边缘，未搭到唱片区域。
   指导：微调唱臂角度与位置，使头部落在唱片中心偏外。
4. **歌词占位区显空**：120px 区域只有一行灰字。
   指导：缩小该区域并让占位文字居中，视觉更收敛。
