# v5 分栏布局对齐网易云平板端

- 右侧歌词：去掉"歌手/专辑/来源"；歌词列铺满视口高度（顶栏改为悬浮层），焦点线 `--lyric-focus: .5` = 列中线 = 视口中线；
  歌词从 55% 宽处左对齐，当前行白色加粗略放大（1.07），其余 42% 白；上下 24% 渐隐；长句自动换行。拖动歌词的时间/「点击从这里播放」定位条同样落在中线。
- 左侧播放器：全部尺寸由唱片直径 `--disc: min(27vw, 46vh)` 推导（标题 .068D、歌手 .05D、进度条宽 1.36D、
  播放键 .2D、上/下一首 .15D、模式/列表 .12D，五点铺满进度条宽度），内容中心位于 25vw。
- 模式图标：顺序 = 跑道形回环 + 右上实心箭头；单曲循环 = 同一回环 + 小"1"；随机为同线宽的交叉箭头。全部自绘 SVG。
- 唱臂：去掉配重尾巴；转轴 = 深色圆形底座 + 白色小旋钮；细白弧形臂管；带细纹的白色矩形唱头。两种布局共用。
- 校验：1280×800 / 1024×667@2x / 1920×1080 / 1024×550 / 2560×1600 下当前行中心与列中心偏差 ≤ 0.08%。
