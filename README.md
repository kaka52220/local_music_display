# 本地音乐播放器（local-player）

纯本地音乐播放器，无账号、无网络、无评论。启动后通过 `http://localhost:8080` 访问。

## 启动

```bash
npm start
# 等价于 node server/index.mjs
```

启动后自动扫描音乐目录。可用环境变量临时覆盖：`PORT=9000`、`MUSIC_DIR=D:\other`、`HOST=127.0.0.1`。
默认音乐目录为项目内的 `music/`（相对路径，相对项目根解析，从任意工作目录启动都能找到）。

## 局域网访问（平板 / 手机）

服务默认监听 `0.0.0.0`（`config/default.json` 的 `host`），同一局域网设备可直接访问。

1. 查本机 WLAN 的 IPv4（如 `192.168.0.108`）。
2. 平板连同一 WiFi，浏览器访问 `http://<本机IPv4>:<端口>`。
3. 若连不上，在 Windows 防火墙放行该端口入站（需管理员）；已存在的 Node.js 放行规则若覆盖当前网络 Profile 则无需操作。

> 注：若默认端口被其他程序占用，用 `PORT=8081 npm start` 换端口启动。

## 界面（v3 · 平板端交互）

- **拖动唱片切歌**：左右拖动/甩动唱片切换上一首/下一首，唱臂抬起落下、旋转联动；按钮切歌同样有滑动动画。
- **歌单弹窗**：左上角按钮或底栏列表按钮打开底部弹窗（搜索、播放模式、定位当前、点歌切换），可下拉/点遮罩/Esc 关闭。原选歌抽屉已移除，首页即播放页。
- **歌词定位**：滚动/拖动歌词显示时间与"点击从这里播放"，3 秒无操作自动回到当前行。
- 视觉方案对比与说明见 `docs/ui-v3-swipe-sheet-scrub.md`、`screenshots/variants/`。

## 已实现

- **黑胶两栏为默认主界面**：进入即黑胶播放页，封面高斯模糊背景。左右两栏等宽：左栏为完整播放列，唱片居中，下方信息/进度/控制块比唱片略宽、内部左对齐；播放控制为 5 个浅色图标、贴两端均匀分布，图标统一在 `icons.mjs` 管理、造型对齐网易云（标准 skip 竖线+三角、圆角播放/暂停、循环/随机、播放列表），尺寸整体放大；播放/暂停是白色大图标（无红色圆底）且居中、明显大于其余，最右为播放列表组件（三等线+小三角，占位、功能待加）。右栏为纯歌词，歌词块限宽左对齐。尺寸用 clamp/vh/vw 弹性自适应，大屏放大、小屏收缩（窄屏自动改为上下堆叠）
- **左侧抽屉选歌**：左上角汉堡（三等线）按钮点击，选歌列表从左侧滑出（默认收起）；点遮罩、按 Esc 或选中歌曲即收起，支持键盘与 aria 无障碍属性
- **会话恢复**：自动记住上次播放的曲目、播放位置与音量（localStorage），再次进入恢复到该曲与位置；浏览器拦截自动播放时保持暂停，手动点播放即从原位置继续
- 右栏歌词：读取同名 .lrc，原生滚动可手动滑动，当前行高亮并定位在容器中心偏上约两行处（下方露出更多后续歌词；小容器下自动钳制，不会推出可视区）；仅手动滚动时悬停行右侧（统一右对齐）显示播放按钮，点击从该句起播，自动播放定位时不显示按钮；兼容纯文本歌词
- 播放 / 暂停、上一首 / 下一首（图标唯一，随状态切换）
- 可拖动进度条（HTTP Range 分段加载）；音量 UI 已移除，引擎音量仍按上次会话恢复
- 三种播放模式：顺序播放、单曲循环、随机播放
- **定时关闭**（v8）：0–90 分钟滑轨 / 播完本首后关闭，到点 4 秒淡出后暂停，按钮显示实时倒计时
- **高潮提示点**（v8）：歌词重复段落 + 音频能量估算副歌起点，进度线上小白点，点击跳转；可用 `[chorus:mm:ss]` 手动指定
- **全屏按钮 + 添加到主屏幕**（v8）：见 `平板访问说明.md`
- UI 评审机制：`docs/ui-review-rubric.md` 为固定清单，每次设计后逐项评审、出指导意见再修改

## 架构与目录

单向依赖：`ui -> state/engine -> api client -> 后端`；引擎封装 `<audio>` 且不依赖 DOM，UI 仅订阅事件。持久化独立封装，不耦合引擎与界面。

```
config/default.json      端口与音乐目录（环境差异唯一入口）
music/                   内置示例曲目（128kbps MP3 + 同名 .lrc）
server/core/             配置、路由、静态服务、MIME
server/domain/track.mjs  Track 领域模型与对外 DTO
server/services/         扫描建库 library、元数据 metadata、歌词 lyrics
server/api/              tracks / stream(Range) / cover / lyrics / chorus（高潮点缓存，写入 cache/chorus.json）
public/                  前端（ES Module 分层：api/state/player/ui）
  js/state/persistence.mjs  会话持久化（曲目/位置/音量，localStorage 容错降级）
  js/player/engine.mjs   播放引擎（封装 audio/队列/模式，不依赖 DOM）
  js/ui/icons.mjs        共享图标库（避免图标重叠）
  js/ui/transport.mjs    播放控制绑定（引擎能力适配到任意视图）
  js/ui/nowPlaying.mjs   黑胶主界面（含歌词滚动高亮）
  js/ui/listView.mjs     抽屉内选歌列表
docs/ui-review-rubric.md 评审清单；ui-review-01/02 为评审记录
```
